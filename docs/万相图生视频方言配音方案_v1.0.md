# 「图片动起来 + 方言配音」方案书（万相版）v1.0

> 产品：安心助手 · 内容形态：15 秒图生视频 + 按用户所在地方言配音
> 状态：待评审 · 全部服务均在国内（阿里云百炼，华北2 北京地域）

## 一、背景与目标

- 产品的内容场景（陪伴相框、回忆视频、资讯口播）需要「照片动起来 + 用户听得懂的方言讲解」。
- 方言不由用户选择，由**首次开机选择的所在地区**自动映射（产品内置静态映射表），降低用户操作成本。
- 目标：单条 15 秒成片成本 ≤ 3 元；内容库批产、端上零生成算力（展锐入门 SoC 不做任何 AI 推理）；同一画面支持多方言复用。

## 二、总体架构

```
用户首次开机选地区 → 端上静态映射表（省/市 → 方言标签）→ 照片上传自家 OSS
        │
        ▼ 云端批产管线（离线，按内容库批量跑）
① 文案：LLM 生成 15 秒口播稿（约 60 字，复用现有豆包/千问链路）
        │
② 音轨：Qwen-Audio-TTS 声音复刻音色 + 指令「请用 XX 话表达」→ 方言 wav 音轨
        │
③ 画面：万相 wan2.6-i2v-flash（无声 720P、duration=15、多镜头）→ 无声 MP4
        │
④ 合成：ffmpeg 将画面与对应方言音轨合成 → 转码 H.264/AAC
        │
        ▼ 自家 OSS + CDN → 平板按用户方言标签拉取对应版本播放
```

关键设计：**画面只生成一次，方言只影响音轨**。同一内容出 N 个方言版本时，③只跑一遍，②每条方言跑一遍（成本可忽略），④按方言合成缓存。

## 三、选型与理由

### 3.1 图生视频：万相 wan2.6-i2v-flash（无声 720P）

| 候选 | 无声 720P 单价 | 15 秒/条 | 结论 |
|---|---|---|---|
| **wan2.6-i2v-flash** | **0.15 元/秒** | **2.25 元** | 选定。成本最低、2–15 秒任意时长、支持智能分镜 |
| wan2.6-i2v（标准） | 0.6 元/秒（有声档） | 9 元 | 画质升级档，A/B 时再上 |
| 可灵 2.6 | 0.3 元/秒 | 4.5 元 | 时长只支持 5s/10s，15 秒需拼接，排除 |
| 即梦 3.0 Pro | ≈1 元/秒 | 15 元 | 成本 4 倍以上，且跨火山第二条账单 |

选定理由：①与 TTS 同属百炼，一张账单一套密钥；②时长 [2,15] 整数任意取，默认 5 秒，正好覆盖 15 秒一条的需求；③支持多镜头叙事（`shot_type: multi`），15 秒由模型自动分镜，避免长镜头漂移；④请求失败不计费，重试无成本。模型页明确其定位即「更快更高性价比」，最高支持 15 秒。

### 3.2 方言配音：Qwen-Audio-TTS 声音复刻 + 指令控制

- 声音复刻音色通过指令文本指定方言，官方示例写法 `请用河南话表达`；官方列出的可指令方言共 21 种：普通话、广东话、重庆话、东北话、甘肃话、贵州话、浙江话、河北话、河南话、湖北话、湖南话、江西话、宁波话、宁夏话、青岛话、陕西话、山西话、山东话、上海话、四川话、云南话。
- 定价：qwen-audio-3.0-tts-flash 1 元/万字符（plus 1.4 元/万字符）；复刻一个音色 0.01 元（每账号 1000 个免费）。
- 选型理由：**「按地区映射方言」要求开放的方言覆盖**，Qwen 复刻 + 指令的 21 种覆盖远超豆包 TTS（仅 4 个音色支持 8 种方言）；复刻一次音色后全国切换只改指令文本。
- 降级路径：不想做复刻时，Qwen3-TTS-Flash 系统音色自带 8 种方言语色（0.8 元/万字符），零成本起步。

### 3.3 文案环节

复用现有 LLM 链路（豆包或千问均可），无新增选型。15 秒口播 ≈ 60 字，单次调用成本 < 0.01 元，可忽略。

## 四、接入细节（参数级）

### 4.1 图生视频（异步任务，两步）

Endpoint（华北2，业务空间专属域名）：
`POST https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis`
Header 必带 `X-DashScope-Async: enable`。

关键入参（**三个默认值都会悄悄抬价/改规格，必须显式传**）：

| 参数 | 必须值 | 默认值陷阱 |
|---|---|---|
| `model` | `wan2.6-i2v-flash` | — |
| `input.img_url` | 公网 URL 或 `oss://` 临时 URL（≤20MB，边长 [240,8000]，JPG/PNG/BMP/WEBP，不支持透明通道） | 画幅由输入图决定，输出宽高为 16 的倍数，不保证精确比例 |
| `input.prompt` | 期望动效描述（≤1500 字符） | — |
| `parameters.resolution` | `720P` | **默认 1080P**（无声档 0.25→0.15 元/秒的差价来源） |
| `parameters.duration` | `15` | **默认 5 秒**，取值 [2,15] 整数 |
| `parameters.audio` | `false` | **默认 true**（有声档 0.3 元/秒）；audio=false 时即使传 audio_url 也输出无声并按无声计费 |
| `parameters.prompt_extend` | `true` | — |
| `parameters.shot_type` | `multi`（15 秒建议开多镜头） | 仅 prompt_extend=true 时生效 |
| `parameters.watermark` | `true`（合规建议，见 6.4） | 默认 false |
| `parameters.seed` | 固定值，便于复现调试 | — |

查询结果：`GET .../api/v1/tasks/{task_id}`，建议 15 秒间隔轮询；**task_id 与 video_url 均只保留 24 小时**，SUCCEEDED 后立即下载转存自家 OSS，不要依赖临时链接。任务通常 1–5 分钟。

自定义音频备选：wan2.6 系列支持 `input.audio_url`（wav/mp3，3–30 秒，≤15MB）让模型按音轨生成有声视频——音画同步更好，但画面与音轨耦合后无法复用画面换方言，本方案主路径不采用，留作单方言爆款内容的备选。

### 4.2 方言 TTS

Endpoint：
`POST https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/audio/tts/SpeechSynthesizer`

```json
{
  "model": "qwen-audio-3.0-tts-flash",
  "input": {
    "text": "〈15 秒口播稿〉",
    "voice": "〈复刻音色 ID〉",
    "instruction": "请用河南话表达。",
    "format": "wav",
    "sample_rate": 24000
  }
}
```

注意：①Qwen-Audio-TTS **仅北京地域可用**；②指令参数 Qwen 系为 `instruction`（Qwen-TTS 系叫 `instructions`，勿混用）；③指令 ≤100 字符；④返回音频 URL 24 小时有效，及时转存 OSS；⑤复刻走 `qwen-voice-enrollment`（0.01 元/音色），需先完成复刻拿到音色 ID；⑥声音设计音色不支持方言，别走这条道。

情感标签：Qwen-Audio-TTS 支持在文本中嵌入 `[excited]`、`[very slowly]` 等控制类标签，口播建议统一 `[very slowly]` + 温柔语气指令。

### 4.3 方言映射表（端上）

- 首次开机选择省/市 → 查内置静态表 → 得到方言标签（如 `henan`、`sichuan`、`cantonese`）+ 对应 TTS 指令文案（`请用河南话表达。`）。
- 命中 21 种之一 → 用方言音轨；未命中 → 就近方言（如映射表配置）→ 仍无 → 普通话兜底。
- 映射表随 App 版本下发，新增方言不需要改代码。
- 维语等民族语言不在 Qwen 覆盖内，走既有讯飞小语种发音人链路（不在本方案范围）。

### 4.4 合成与分发

- ffmpeg 将无声 MP4 + 方言 wav 合成为 H.264/AAC 的 MP4（平板硬解友好），转码后上传 OSS，CDN 分发。
- 同一内容的多方言版本以 `{content_id}/{dialect}.mp4` 组织；合成结果缓存，重复请求直接命中。
- 平板端：内容元数据（content_id、标题、可用方言列表）走既有配置下发通道，播放按本机方言标签选源。

## 五、成本估算

单条 15 秒成片（720P）：

| 环节 | 用量 | 单价 | 小计 |
|---|---|---|---|
| 图生视频 | 15 秒 | 0.15 元/秒 | 2.25 元 |
| 方言 TTS | ≈60 字 ≈ 120 字符 | 1 元/万字符 | ≈0.012 元 |
| LLM 文案 | <1K tokens | 现有链路 | ≈0.001 元 |
| **合计** | | | **≈2.26 元/条** |

规模化（一次性内容库）：

| 内容库规模 | 一次性成本 |
|---|---|
| 50 条 | ≈113 元 |
| 100 条 | ≈226 元 |
| 500 条 | ≈1,130 元 |

免费额度可覆盖全部验证期：视频 50 秒（≈3 条 15 秒）、TTS 1 万字符、复刻音色 1000 个。

成本结构结论：**图生视频占 99% 以上**，降本杠杆是「画面一次生成、多方言复用」与「少生成」（内容库批产、失败重试不计费），不是换厂商。

> 补充（本仓库口径）：以上为「图生视频 `wan2.6-i2v-flash`」口径。本仓库的**文生视频 / 主讲人**路径走 `wan3.0-video`（720P 限时7折 ¥0.42/秒、原价 ¥0.6/秒，**只按输出秒数计费**），15 秒 ≈ **¥6.3（折）/ ¥9（原价）**，约为 i2v-flash 的 2.8–4 倍。单价与计费口径详见 [万相视频生成与编辑成本核算 v1.0](万相视频生成与编辑成本核算_v1.0.md)。

## 六、授权与合规红线

1. **声音复刻授权**：复刻任何真人声音（家人、主播、用户本人）必须取得本人明示同意，产品内需有授权确认环节并留痕。
2. **用户照片属敏感个人信息**：云端处理前需告知并取得同意，与产品现有隐私政策对齐；建议使用「上传文件获取临时 URL」方式传输，避免公网裸链。
3. **AI 生成内容标识**：按《人工智能生成合成内容标识办法》，建议显式开启 `watermark=true`（视频右下角「AI生成」角标），分发元数据中同步保留生成信息。
4. **内容审核**：万相与 TTS 均有过滤机制，输入 prompt/图像与输出视频都会被审核，违规返回 IPInfringementSuspect / DataInspectionFailed；批产管线需把审核失败纳入重试与人工复核流程。
5. **商用条款**：百炼各模型商用以阿里云百炼服务协议为准，批量采购前过一遍协议中生成内容权属与商用条款（评审待办，以官方协议页为准）。

## 八、风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 真人照片 i2v 面部扭曲（恐怖谷） | 高 | 人物照片不上 i2v：降级为 Ken Burns 缓动镜头或微动效；风景/物品/宠物正常 i2v |
| 15 秒长镜头画面漂移 | 中 | `shot_type: multi` 多镜头分镜；prompt 明确运动幅度；固定 seed 便于复现调优 |
| 方言自然度不达标（部分方言指令效果弱） | 中 | M0 先实测目标地区方言；不达标地区就近方言或普通话兜底 |
| 21 种方言外地区（维语、客家话等） | 中 | 普通话兜底；民族语言走既有讯飞链路 |
| 临时 URL 24 小时过期导致内容丢失 | 低 | SUCCEEDED 后立即转存自家 OSS；管线内「转存成功」才标记任务完成 |
| 圆形物体连续旋转 3 秒后出现卡顿（官方已知限制） | 低 | 表盘/齿轮类画面改用万相 2.7 或避开旋转构图 |
| 限流（RPM 300）影响批产吞吐 | 低 | 批产速率远低于限流；峰值时排队即可 |
